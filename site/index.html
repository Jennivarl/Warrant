Attested

A fact nobody had to be trusted for.

GitHub had a critical outage on 17 August. Every validator on the network fetched GitHub's own status page, agreed on what it said, and a contract paid out because of it. No oracle, no operator, no model. Everything on this page is read live from the chain.

How it fits together

Two contracts, one job each.

Splitting them is the point. Reading the web honestly is a hard problem on its own, so it lives in its own contract that anything can reuse. Deciding what a fact is worth is a different problem, and it never touches the network.

Live from Signal

Three answers, not two.

Most oracles have one failure mode: a value, or an error. That collapse is where the attack lives, because it lets whoever reports the fact turn a source that said nothing into a source that was broken. These are three different claims about the world, and they are kept apart. Each card below is a real key read on chain.
